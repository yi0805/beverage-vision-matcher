# Project guardrails

This is intentionally a small, one-day classical computer-vision experiment.
Prefer simple, readable Python and small independently testable CV functions over
architectural complexity. Do not add web, API, database, cloud, Docker, or
deep-learning scope—or implement future tasks early—without explicit approval.

Accuracy and performance claims require real measured results: never invent
experimental results or describe planned work as complete. Do not commit private
photographs, credentials, or secrets. Documentation must match the implementation.
Run relevant verification before completion, do not automatically merge branches,
and do not create `ROADMAP.md` or handoff files.
